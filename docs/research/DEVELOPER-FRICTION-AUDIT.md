## Net

The path an outsider takes today is: read ADRs, copy Checkers (not merged), hand-write a Python process against two
vendored files, edit three Party files, and ask the owner to provision it. Strongest blockers: no scaffold or Hello
Party (2), no non-Linux local run (4), the duplicated process plumbing (5, 7), no third-party test kit (13), and
an owner-run provisioning step with no package (10, 15). Several of these are *by gate*, not by omission (AVR-37/38/39/59).
