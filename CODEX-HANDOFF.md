# Agent entry point

Use current GitHub `main` for source and the current issue in
[Linear](https://linear.app/avranakern) for scope, priorities, blockers, acceptance and ownership.
No handoff assigns the next task or authorizes a deployment.

Read [CLAUDE.md](CLAUDE.md), [SYSTEM](docs/SYSTEM.md), [TESTING](docs/TESTING.md), then the relevant
[ADRs](docs/adr/) and [design docs](docs/design/README.md). [ROADMAP](docs/ROADMAP.md) describes
strategic direction. Merged source may be ahead of verified production.

The former providerization handoff is preserved in Git history as a dated sprint record.
Its branch names, review order and next-action instructions are no longer authoritative.
Develop on an issue-scoped branch, open a PR, and follow owner-approved deployment rules.
